📊 Word Count with Hadoop MapReduce

A practical university assignment for the Big Data course, implementing the classic Word Count algorithm using Apache Hadoop MapReduce (Java / Python).

🚀 Introduction

This project counts the frequency of each word in a large text dataset by leveraging the distributed computing model of Apache Hadoop MapReduce.

🛠️ Technologies Used

🐘 Hadoop (HDFS & MapReduce)

💻 Java / Python (depending on the assignment setup)

🐧 WSL2 / Ubuntu (execution environment)
